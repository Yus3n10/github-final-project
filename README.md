Introduction to Git and GitHub - Simple Interest Calculator

Project Name

mcino-Introduction-to-Git-and-GitHub

Description

This repository contains a Simple Interest Calculator, a Bash script that computes simple interest based on user input. It was created as part of the Final Project for the "Introduction to Git and GitHub" course, demonstrating practical use of Git and GitHub workflows including forking, cloning, branching, committing, and pull requests.

About the Script

The simple-interest.sh script prompts the user for three inputs:


Principal amount – the initial sum of money
Rate of interest – the annual interest rate (%)
Time period – the duration in years


It then calculates the simple interest using the formula:

Simple Interest = (Principal x Rate x Time) / 100

and displays the simple interest along with the total amount (principal + interest).

How to Run

bashchmod +x simple-interest.sh
./simple-interest.sh

Follow the on-screen prompts to enter the principal, rate, and time period.
